# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within DioramaOps, please do not file a public issue. Instead, report it privately:

1. Email security reports directly to: `security@dioramaops.org` (or contact repository owners privately via GitHub Security Advisories).
2. Please include:
   - A description of the issue and potential impact.
   - Step-by-step reproduction instructions or proof-of-concept (PoC).
   - Any suggested mitigations or patches.

We will acknowledge receipt within 48 hours and work with you to release a fix promptly.
